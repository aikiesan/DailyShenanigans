# Fotos dos exercícios

Coloque as fotos aqui com **exatamente** estes nomes (JPG, paisagem, de lado,
~800px de largura, proporção ideal 5:3). O app usa a foto automaticamente e
volta para a ilustração se o arquivo não existir.

## Exercícios
| Arquivo | Exercício |
|---|---|
| `dead_bug.jpg` | Dead Bug (deitado de costas, braço e perna opostos estendidos) |
| `bird_dog.jpg` | Bird Dog (quatro apoios, braço e perna opostos estendidos) |
| `glute_bridge.jpg` | Ponte de Glúteo (quadril elevado no topo) |
| `hollow_hold.jpg` | Hollow Body Hold (posição banana) |
| `pushup.jpg` | Flexão de braço (prancha, cotovelos flexionados) |
| `pike_pushup.jpg` | Pike Push-up (V invertido, cabeça entre as mãos) |
| `inverted_row.jpg` | Remada Invertida (embaixo da barra/mesa) |
| `pullup.jpg` | Barra Fixa (pendurado ou no topo) |
| `squat.jpg` | Agachamento Livre (posição baixa) |
| `sl_rdl.jpg` | RDL Unilateral (dobradiça, perna traseira estendida) |
| `wall_sit.jpg` | Cadeirinha na Parede (joelhos a 90°) |
| `burpee.jpg` | Burpee com Passo Atrás (posição de prancha ou passo) |
